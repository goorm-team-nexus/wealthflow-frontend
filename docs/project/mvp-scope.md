# MVP Scope

## 1차 핵심 플로우

- MUST 카카오 로그인을 1차 핵심 플로우에 포함한다.
- MUST 시장/종목 검색을 1차 핵심 플로우에 포함한다.
- MUST 종목 상세를 1차 핵심 플로우에 포함한다.
- MUST 모의 매수/매도를 1차 핵심 플로우에 포함한다.
- MUST 포트폴리오를 1차 핵심 플로우에 포함한다.
- MUST 거래 내역을 1차 핵심 플로우에 포함한다.

## MVP 포함 기능

- MUST 관심 종목을 MVP 포함 기능으로 본다.
- MUST 랭킹을 MVP 포함 기능으로 본다.
- MUST 뉴스 + AI 요약을 MVP 포함 기능으로 본다.
- MUST 환전을 MVP 포함 기능으로 본다.
- MUST 자산 리포트를 MVP 포함 기능으로 본다.

## 일정 위험 시 축소 대상

- EXCEPTION 일정 위험 시 AI 요약 품질 고도화는 축소 대상에 포함한다.
- EXCEPTION 일정 위험 시 랭킹 고도화는 축소 대상에 포함한다.
- EXCEPTION 일정 위험 시 리포트 상세 시각화는 축소 대상에 포함한다.
- EXCEPTION 일정 위험 시 실자산 수기 등록/관리는 축소 대상에 포함한다.

## 범위 판단

- MUST MVP 포함 기능은 명시적 축소 지시가 없으면 구현 범위로 본다.
- MUST 범위를 벗어나는 기능은 구현 전에 사용자에게 확인한다.
